# BallBounce

**Orbs** — a physics toy for the iPhone Home Screen. Small glowing balls in near-zero
gravity; your finger is a force field. Vanilla JS + Canvas 2D, no build step, no
dependencies.

The app lives in [`orbs/`](orbs/). **Start with [`orbs/README.md`](orbs/README.md)** for
running it, installing it, deploying it, and how it is put together.

```sh
cd orbs && node test.js          # tests: zero installs, node:assert only
cd orbs && python3 -m http.server 8080   # then open http://localhost:8080/
```
